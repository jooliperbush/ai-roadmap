# Miscited Replacement Implementation Plan

> **For agentic workers:** Use subagent-driven-development for bounded subsystem implementation and review. Independent file ownership permits parallel domain, service and presentation work under dispatching-parallel-agents. Do not modify another worker's files.

**Goal:** Rebuild Miscited against the existing application's behavioral specification with stronger architecture and demonstrable regression protection.

**Architecture:** Preserve external contracts and released data migrations while replacing the application by independent modules. The original checkout is the immutable reference; the dedicated worktree is the candidate. Tests precede each subsystem's replacement and remain unchanged unless they inspect obsolete internal structure rather than behavior.

**Tech Stack:** Node 22+, TypeScript, Fastify 5, better-sqlite3, Vitest, Playwright, semantic server-rendered HTML/CSS.

## Progress convention

Check an item only when its evidence exists. Do not describe a copied file, a compatibility re-export or moved code as a fresh implementation. A subsystem that remains unchanged must be listed as outstanding, even if its inherited tests pass.
